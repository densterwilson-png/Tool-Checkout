Equipment Checkout System (ECS)


Setup Instructions

1.	Download or clone the project repository.
2.	Open the project in a Java IDE (Apache NetBeans recommended).
3.	Allow Maven to download required dependencies.
4.	Build the project.
5.	Run Main.java.

   
Requirements
•	Java JDK 21 or later
•	Maven


Notes
•	Database tables are automatically created during startup.
•	Sample data is automatically loaded during the first execution.
